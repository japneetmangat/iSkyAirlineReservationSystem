# iSkyAirlineReservationSystem
- master user is prompted to create an account
- master user prompted to change password and sign back in
- prompted to create at least one account for each of the three types of employees (Business Manager, LOB Exec, Network Admin)
- employees can log in using their given username and password, then are prompted to change their password
- Business Managers can create/add/remove flights and flight information from the database
